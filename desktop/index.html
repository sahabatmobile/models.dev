Integrasi TRAE (trae.ai)

Hubungkan AI Gateway SahabatMobile ke Trae lewat menu Custom Model.

  1. Buka Trae → Settings → Models → Add Model.
  2. Pilih Custom Model (bukan provider preset).
  3. Isi field di bawah ini persis, lalu klik Add Model.
  4. Pilih model SahabatMobile di pemilih model Trae, lalu mulai chat.
